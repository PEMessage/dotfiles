# tr31-tool

> Parse, decrypt, encode and encrypt ANSI X9.143 / TR-31 / ISO 20038 key blocks

- Decode (parse only, no decryption) a type B key block:

`tr31-tool --import B0128B1TX00N0300KS18FFFF00A0200001E00000KC0C000169E3KP0C00ECAD626F9F1A826814AA066D86C8C18BD0E14033E1EBEC75BEDF586E6E325F3AA8C0E5`

- Decrypt type A (TDES Variant binding, TR-31:2018 A.7.2.1):

`tr31-tool --import A0072P0TE00E0000F5161ED902807AF26F1D62263644BD24192FDB3193C730301CEE8701 --kbpk 89E88CF7931444F334BD7547FC3F380C`

- Decrypt type B (TDES Derivation binding, TR-31:2018 A.7.2.2):

`tr31-tool --import B0080P0TE00E000094B420079CC80BA3461F86FE26EFC4A3B8E4FA4C5F5341176EED7B727B8A248E --kbpk DD7515F2BFC17F85CE48F3CA25CB21F6`

- Decrypt type C (TDES Variant binding with KSN, TR-31:2018 A.7.3.1):

`tr31-tool --import C0096B0TX12S0100KS1800604B120F9292800000BFB9B689CB567E66FC3FEE5AD5F52161FC6545B9D60989015D02155C --kbpk B8ED59E0A279A295E9F5ED7944FD06B9`

- Decrypt type D (AES Derivation binding, 256-bit KBPK, TR-31:2018 A.7.4):

`tr31-tool --import D0112P0AE00E0000B82679114F470F540165EDFBF7E250FCEA43F810D215F8D207E2E417C07156A27E8E31DA05F7425509593D03A457DC34 --kbpk 88E1AB2A2E3DD38C1FA039A536500CC8A87AB9D62DC92C01058FA79F44657DE6`

`tr31-tool --import E0084B0TV16N0000B2AE5E26BBA7F246E84D5EA24167E208A6B66EF2E27E55A52DB52F0AEACB94C57547 --kbpk 3235362D62697420414553207772617070696E67202849534F20323030333829`

`tr31-tool --import D014410A100N0200101CIBMC01140123456789ABCDEFPB04012345678901234567890123456789012345678901234567890123456789012345678901234567890123456789012345 --import-no-strict-validation`

- Export (encrypt) using header template:

`tr31-tool --kbpk AB2E09DB3EF0BA71E0CE6CD755C23A3B --export BF82DAC6A33DF92CE66E15B70E5DCEB6 --export-header B0000B1TX00N0000`

- Export with optional blocks (KS, KC, LB):

`tr31-tool --kbpk AB2E09DB3EF0BA71E0CE6CD755C23A3B --export BF82DAC6A33DF92CE66E15B70E5DCEB6 --export-header B0000B1TX00N0000 --export-opt-block-KS FFFF00A0200001E00000 --export-opt-block-KC --export-opt-block-LB MyLabel`

- Export using format version, key algorithm, and template:

`tr31-tool --kbpk AB2E09DB3EF0BA71E0CE6CD755C23A3B --export BF82DAC6A33DF92CE66E15B70E5DCEB6 --export-format-version B --export-key-algorithm TDES --export-template KEK`

- Read key from stdin:

`echo -n "rawkeydata" | tr31-tool --import - --kbpk AB2E09DB3EF0BA71E0CE6CD755C23A3B`
